# Devin Desktop Configuration

This directory contains Devin Desktop project-specific configuration.

## Files

- `config.json` - Project permissions and MCP server settings
- `AGENTS.md` - Project-specific agent rules and guidelines
- `skills/` - Custom skills for this project

## Usage

When you open this project in Devin Desktop, it will automatically load this configuration.
