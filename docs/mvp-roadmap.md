# MVP Roadmap

## Slice 1: Foundation

- Monorepo, shared contracts, Prisma schema, local Postgres/Redis, API/compliance shells, backoffice dashboard shell.

## Slice 2: Inventory and Goods Receipt

- Product catalog, supplier PO, goods receipt, batch/expiry tracking, BPOM DataMatrix verification stub-to-real adapter.

## Slice 3: Dispensing and Compliance Queue

- Sale/dispensing workflow, inventory decrement, SatuSehat job creation, Coretax invoice status tracking, QRIS provider abstraction.

## Slice 4: e-MESO Assist

- Adverse event capture, consent validation, portal-assisted/API submission workflow, compliance dashboard triage.

## Slice 5: Offline POS

- React Native or PWA implementation, local store, sync envelopes, conflict resolution, offline receipts.
